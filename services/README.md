# Services

This directory contains the backend services that power the Sentra Brain platform. Each subfolder is a separate service, such as the API Gateway, LLM Server, MCP Server, and RAG Engine.

## Services Overview
- **api-gateway**: Entry point for client requests, routing and aggregating API calls.
- **llm-server**: Provides large language model capabilities.
- **mcp-server**: Implements the Model Context Protocol for advanced context management.
- **rag-engine**: Handles retrieval-augmented generation tasks.

Refer to `/docs/arc42/05_building_block_view.md` and `/docs/arc42/06_runtime_view.md` for more information on service interactions and architecture.
