# Apps

This directory contains the main application frontends for the Sentra Brain project. Each subfolder represents a different application, such as the Control Panel and Webapp.

## Applications
- **control-panel**: Administrative interface for managing and configuring the Sentra Brain system.
- **webapp**: User-facing web application for interacting with Sentra Brain features.

For more details on the overall architecture and application roles, see the documentation in `/docs/arc42/` (especially `05_building_block_view.md` and `03_context_and_scope.md`).
