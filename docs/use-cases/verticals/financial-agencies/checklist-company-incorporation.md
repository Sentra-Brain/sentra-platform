# Use Case: Checklist for Company Incorporation

**Category:** Vertical — Financial Agencies (Tax Agencies)  
**Actors:** Authenticated User (Agent), Sentra Brain System  
**Priority:** High  
**Triggers:** User requests checklist for incorporating a new company  

## Description

Provides financial and legal advisors with a step-by-step checklist required to incorporate a company in Spain, including required forms, legal steps, and administrative procedures.  
Helps streamline client onboarding for new businesses.

## Basic Flow

1. User logs into Sentra Web.
2. User accesses the “Company Incorporation” checklist tool.
3. User selects company type:
    - Sociedad Limitada (SL)
    - Sociedad Anónima (SA)
    - Autónomo
4. Sentra Brain displays:
    - Required documents (e.g., NIE, ID, company statutes).
    - Step-by-step actions (e.g., Registro Mercantil, Tax ID, Social Security registration).
    - Estimated timelines and associated costs.
5. User can mark each step as completed.
6. User can download or print the checklist.

## Extensions

- MCP integration with gestoría tools to track status automatically.
- Admin UI allows updating default checklists if laws change.

## Notes

- Checklist content is country-specific.  
- Designed as an advisory tool: final legal responsibility remains with certified professionals.
