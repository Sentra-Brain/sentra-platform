# Use Case: Automate Employee Onboarding Checklist

**Category:** Vertical — General Business  
**Actors:** Authenticated User (HR Staff), Sentra Brain System  
**Priority:** High  
**Triggers:** New employee registration  

## Description

Sentra Brain provides automated onboarding checklists for new hires, customized by role or department, helping HR ensure all steps are completed consistently.

## Basic Flow

1. HR staff logs into Sentra Web.
2. User creates a new onboarding checklist for a new employee.
3. System presents default checklist including:
    - Account creation.
    - Equipment assignment.
    - Policy signature collection.
4. User can customize checklist items.
5. Checklist can be saved, printed, or shared.

## Extensions

- MCP integration with HR software or ERP.
- Status tracking for onboarding steps.

## Notes

- Designed as an advisory/tracking tool, not a full HR management system.
