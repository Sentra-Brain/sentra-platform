# Use Case: Draft Company Announcement

**Category:** Vertical — General Business  
**Actors:** Authenticated User (Admin, Manager), Sentra Brain System  
**Priority:** Medium  
**Triggers:** User requests help drafting a communication  

## Description

Sentra Brain assists in drafting internal or public company announcements, including news, policy updates, or event notifications.

## Basic Flow

1. User logs into Sentra Web.
2. User opens the “Communications” tool.
3. User provides event details (what, who, when, tone).
4. Sentra Brain generates:
    - Email draft.
    - Social media post (optional).
    - Printable notice version.

## Extensions

- Integration with CMS or email platforms via MCP.
- Multi-language announcement generation.

## Notes

- Final approval and sending managed by human users.
