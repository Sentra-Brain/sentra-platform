# Use Case: Summarize Internal Report

**Category:** Vertical — General Business  
**Actors:** Authenticated User (Employee, Manager), Sentra Brain System  
**Priority:** High  
**Triggers:** User uploads or pastes an internal report  

## Description

Sentra Brain helps employees summarize long internal reports, meeting notes, or strategy documents into key points and actionable insights.  
Useful for management reviews and cross-team communication.

## Basic Flow

1. User logs into Sentra Web.
2. User accesses the “Summarization” tool.
3. User uploads or pastes report content.
4. Sentra Brain processes the document using LLM summarization.
5. System displays:
    - Executive summary.
    - Bullet point list of key decisions.
    - Suggested follow-up actions.

## Extensions

- Summarization style options: short, detailed, action-focused.
- Multi-language support.

## Notes

- Works offline if privacy is a concern.
- Document retention period configurable by admin.
