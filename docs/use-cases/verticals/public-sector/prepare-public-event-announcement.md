# Use Case: Prepare Public Event Announcement

**Category:** Vertical — Public Sector  
**Actors:** Authenticated User (Public Agent), Sentra Brain System  
**Priority:** Medium  
**Triggers:** User requests help drafting or formatting a public communication  

## Description

City hall communication teams can use Sentra Brain to automatically generate announcement drafts for public events, including basic formatting, legal disclaimers, and multi-language versions.

## Basic Flow

1. Public agent logs into Sentra Web.
2. User opens the “Public Communications” section.
3. User submits event details:
    - Event name, date, location, description.
4. Sentra Brain generates:
    - Announcement text.
    - Suggested email, social media post, and PDF flyer drafts.
    - Translations into configured languages (Spanish, English, Catalan, etc.).
5. User reviews and downloads or sends announcements.

## Extensions

- MCP integration with public website CMS or social media management platforms.
- Admin templates for different event types.

## Notes

- Human review always required before publishing public announcements.
- Reduces repetitive writing tasks for routine municipal communications.
